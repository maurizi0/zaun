Proxy allow

HTTP/HTTPS targets agents may reach through the proxy (port 3128). HTTPS is decrypted, so path rules work for both. Examples: test.host.io, *.host.io, http://test.io, https://api.x.io/v1/*, 42.42.42.42, host.io:8443. Without a port only the default ports (80/443) match. WebSockets are denied by default. Enable Allow WebSockets on a rule to permit upgrades within each target’s port and path. Separate multiple targets with commas to create a group; On and Allow WebSockets apply to the whole group.

Deny rules

Deny rules are evaluated before every allow rule and always win, e.g. http://test.io/*, *.host.io/admin/*, evil.host.io. Use */admin* to block paths starting with /admin on any host, or */*admin* to match admin anywhere in the path. Without an explicit port, targets match default HTTP/HTTPS ports only. Separate multiple targets with commas to create a group with one On switch. Path matching for deny rules is case-insensitive; percent-encoded paths are not normalized.

Firewall

Direct (non-HTTP) connections, enforced with nftables — e.g. 42.42.42.42 port 3306. Targets may be an IP, a CIDR or a hostname (re-resolved periodically). Ports: 3306, 5432,6379, 8000-8100. Connections leaving the pod are rejected unless allowed, except the proxy's own traffic.
