Proxy allow

HTTP/HTTPS targets agents may reach through the proxy (port 3128). HTTPS is decrypted, so path rules work for both. Examples: test.host.io, *.host.io, http://test.io, https://api.x.io/v1/*, 42.42.42.42, host.io:8443. Without a port only the default ports (80/443) match. WebSockets are denied by default. Enable Allow WebSockets on a rule to permit upgrades within its target, port and path.

Deny rules

Deny rules are evaluated before every allow rule and always win, e.g. http://test.io/*, *.host.io/admin/*, evil.host.io. Path matching for deny rules is case-insensitive.

Firewall

Direct (non-HTTP) connections from the pod, enforced with nftables — e.g. 42.42.42.42 port 3306. Targets may be an IP, a CIDR or a hostname (re-resolved periodically). Ports: 3306, 5432,6379, 8000-8100. Everything else leaving the pod is rejected, except the proxy's own traffic.
